# Smart Pantry Manager

Smart Pantry Manager is an Android application developed for the Mobile App Development 700 assignment.

## About the App

The application allows users to manage ingredients stored in their pantry and view recipes that can be made using the ingredients they currently have.

## Features

- Add pantry ingredients
- Edit existing ingredients
- Delete ingredients
- Store ingredient quantities and units
- View all pantry ingredients
- View suggested recipes
- Strict recipe matching based on available ingredients and quantities
- View recipe details
- Settings screen
- Persistent data storage using SQLite
- Navigation between application screens

## Recipe Matching

A recipe is suggested only when all of its required ingredients are available in the pantry in sufficient quantities.

The application also handles simple ingredient name differences, such as singular and plural forms.

## Technologies Used

- Java
- Android Studio
- SQLite
- RecyclerView
- XML layouts
- Android Intents

## Minimum Android Version

Minimum SDK: API 24
